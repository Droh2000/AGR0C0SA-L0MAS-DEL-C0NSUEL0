h1. Web Para La Empresa Agrocosa 

Esta es una pagina administrativa con usuarios, roles y modulos para la gestion y administracion de la empresa del ambito agropecuario

* Proyecto debe ser abierto en Netbeans
* Seleccionar cada unas de las librerias que se nos indican en la configuracion
* La base de datos esta desarrollada en MySQL server que no se subira por temas de seguridad de la empresa
* Realizar un Clean and Build
* Run Proyect

La pagina en produccion esta subida a un servidor de Tomcat, donde se despliguan ahi los nuevos cambios que se generan en el archivo .war que se nos crea al hacer Clean and Build
